## What this is

A single-page site that shows how I think about content instead of listing past work:

- **Series idea:** "Element 79", short jewellery-science episodes with a hook, a fact and a BlueStone angle.
- **Tap-to-flip fact cards:** four sample episodes.
- **Sample storyboard:** a 20-second reel, shot by shot.
- **Format adaptation:** how one idea works across film, social, stills, print, out-of-home and in-store.
- **Shoot method:** brief, references, shot list, talent and crew, on set, review.
- **About me:** background, achievements and contact details.

## Run it locally

Download `index.html` and double-click it. It opens in any browser. The only external resource is Google Fonts, and there are fallback fonts if it can't load.

## Publish it

**Netlify Drop:** put `index.html` in a folder and drag the folder onto app.netlify.com/drop.

**GitHub Pages:** upload `index.html` to a public repository, then go to Settings → Pages, choose the `main` branch and save. The link will be `https://<username>.github.io/<repo-name>`.

## Edit it

- **Facts and episodes:** search for `class="flip"` in `index.html`. Each card has a front (the hook) and a back (the fact and the BlueStone angle).
- **Storyboard:** edit the `fr` list in the `<script>` at the bottom.
- **Format tabs:** edit the `fm` list in the same script.
- **Contact details:** search for `mailto:` and `tel:`.
- **Colours:** change the variables at the top of the `<style>` block (`--gold`, `--hero`, `--bg`).
